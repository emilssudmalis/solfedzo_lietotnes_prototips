Projekta nosaukums: Solfedžo mācību lietotnes prototips

Apraksts: Šeit pieejams pirmkods solfedžo mācību tīmekļa lietotnes prototipam, kuru autors veidojis bakalaura darba izstrādes ietvaros. 

Prototipa izveidē izmantots GitHub Copilot rīks, kā arī RapidNative, lai ģenerētu krāsu paleti. Šī lietotne paredzēta mūzikas skolas agrīno klašu skolēniem kā papildrīks solfedžu mācību procesā. Šajā lietotnē uzlaboti/mainīti citu eksistējošu lietotņu trūkumi, kā mehāniskas mācīšanās jeb _rote learning_ principi, uzdevumu dekontekstualizācija, pedagoģisko teoriju iesaistes trūkums u.c. Jāatgādina, ka projekts ir prototipa stadijā, tādēļ izstrādāta ir tikai tercu tēma, pārējās tēmas nav izstrādātas.
