**Projekta nosaukums:** Solfedžo mācību lietotnes prototips

**Apraksts:** Šeit pieejams pirmkods solfedžo mācību tīmekļa lietotnes prototipam, kuru autors veidojis bakalaura darba izstrādes ietvaros. 

Prototipa izveidē izmantots GitHub Copilot rīks, kā arī RapidNative, lai ģenerētu krāsu paleti. 

Šī lietotne paredzēta mūzikas skolas agrīno klašu skolēniem kā papildrīks solfedžu mācību procesā. 

Šajā lietotnē uzlaboti/mainīti citu eksistējošu lietotņu trūkumi, kā mehāniskas mācīšanās jeb _rote learning_ principi, uzdevumu dekontekstualizācija, pedagoģisko teoriju iesaistes trūkums u.c. 

Jāatgādina, ka projekts ir prototipa stadijā, tādēļ izstrādāta ir tikai tercu tēma, pārējās tēmas nav izstrādātas.

**Galvenās iespējas:** 

* Mācīties solfedžo teoriju;

* Pildīt uzdevumus, kuru grūtības pakāpe automātiski pielāgojas, atkarībā no atbildēm

* Iegūt balvas par pabeigtām tēmām.

**Instalēšana:** 

* Uzinstalējiet Flutter un Dart (https://flutter.dev/docs/get-started/install)

* Uzinstalējiet Git (https://git-scm.com/install/)

* Klonējiet repozitoriju:

git clone https://github.com/your-username/QuizApp-Flutter.git

cd QuizApp-Flutter

* Instalējiet _dependencies_

flutter pub get

* Pārbaudiet Flutter instalāciju

flutter doctor

* Palaidiet lietotni

flutter run -d chrome (ja vēlaties to palaist Chrome pārlūkā)

**Lietošana:** 

1. Palaidiet lietotni

2. Autentificējieties vai reģistrējieties

3. Izvēlieties apgūstamo tēmu (piemēram, tercas)

4. Spiediet uz Sākt pogas

5. Turpiniet mācību proces, līdz esat tēmu apguvuši
